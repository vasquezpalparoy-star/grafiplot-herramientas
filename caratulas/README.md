# Grafiplot Carátulas

Creador de carátulas UDH y UNHEVAL integrado en Grafiplot Herramientas.

Abre `web/index.html` mediante un servidor web. Incluye 29 logos, listas vinculadas de facultades y carreras, trabajo individual/grupal, tipografía y espaciado, borde opcional, exportación PDF A4 y solicitud de impresión por WhatsApp. Grafiplot se muestra solo en la interfaz; no se añade al PDF.

## Android

El proyecto `android/` usa Java 17, Gradle 8.9, SDK 35 y Build Tools 35.0.0. Abre `android/` en Android Studio, sincroniza y compila `assembleDebug`. Los recursos web se comparten desde `web/`. El APK de prueba está firmado para instalación manual; la prueba en un teléfono real queda pendiente. No hay claves privadas ni archivos de usuarios en este repositorio.
